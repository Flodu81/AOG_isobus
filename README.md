Software set and ino to use the isobus through the can of the pcb steer and the udp. The basic ino and the modifications of the vt were made by paulius. 
The other modifications of agio and the task control are mine. 
The base code for ecu was created by buched,
The was added to the waskeya.

Not all of them have been tested yet

To use if you have an ecu you just have to adapt the number of can, for the aio you have to add the bridge to the ino steer.

Then installed taskControler, and launched the vt if needed, connect your pcb in udp as usual the 1st time in the isobus configuration choose Isobridge 

The next time you use it, everyone must be connected alone , an isobus icon and added directly with the PCB icon to verify the connection

Now enjoy
